# Direct Sales Portal: clickable prototype

A single-page demo of the Bahrain direct-sales portal. It contains:
- passkey sign-in (simulated);
- agent punch-in and punch-out with a live selfie and location;
- schedule, leave and attendance screens;
- a manager view with punch-in photos, a team map, exception review and leave approvals.

All data is fictional, and nothing is sent to a server. Everything resets when the page reloads.

## Demo accounts

- **Agent:** tap **Sign in with a passkey** and pick **Noor Hasan**, or sign in with `agent.noor` and any password.
- **Manager:** pick **Khalid A.**, or sign in with `manager.khalid`, any password and any 6-digit code.

## Hosting on GitHub Pages

1. Create a new repository and upload `index.html` (and this README).
2. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, then save.
3. After a minute, open `https://<your-username>.github.io/<repo-name>/` on your phone.

GitHub Pages serves over HTTPS, so the phone's real camera and GPS work. Allow them when the browser asks.

**Keep the repository private if your plan allows it.** On a free plan, a Pages site from a public repository is visible to anyone who has the link.
